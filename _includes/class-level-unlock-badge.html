{%- comment %} Renders the hover/click tooltip for a level-track node on a single class's own page. Unlike level-unlock-badge.html (used on the main Classes page, which lists every class's unlock at a given level with a "Class | Card" two-column layout and an "All Classes" collapsing row), this only ever needs to show what THIS ONE class unlocks there - so no per-class column, no All-Classes case. Almost always exactly one card; occasionally two (e.g. two Heroic skins both unlocking at the level cap), so it's still a list rather than a single fixed slot. Reuses the exact same .level-badge__tip/-preview/-list/-card CSS as the multi-class version (see _sass/home.scss) with a &--single modifier that collapses the "Class | Card" grid down to one column, and the same shared-preview-slot hover pattern established there (see that file's comment for why it's one slot per tooltip, not one per row) - classes/index.html's card-preview JS (clampPreviewHorizontal/Vertical/IntoView, showLevelCardPreview) is ported into this page's own
