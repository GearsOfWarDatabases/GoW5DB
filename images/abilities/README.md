# Ability Images

Place ability spell/icon images here. Three PNGs per class:

Pattern: `{class-slug}-{type}.png`

Types: `passive`, `active`, `ultimate`

Examples:
- `anchor-passive.png`
- `anchor-active.png`
- `anchor-ultimate.png`
- `brawler-passive.png`
- `brawler-active.png`
- `brawler-ultimate.png`
- ... (same pattern for all 12 classes)

Recommended size: 128x128px (square).
