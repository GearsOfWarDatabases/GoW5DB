# Class Icons

One PNG per class, named exactly as the class slug. Extracted from the in-game
CLASSES menu sidebar (`ref/Class Menus/*.jpg`) - white glyph on transparent
background, matching the other icon sets on the site (fortifications,
abilities).

- `blademaster.png`
- `demolitions.png`
- `infiltrator.png`
- `marksman.png`
- `nomad.png`
- `anchor.png`
- `brawler.png`
- `gunner.png`
- `pilot.png`
- `veteran.png`
- `combat-medic.png`
- `jack.png`
- `mechanic.png`
- `robotics-expert.png`
- `tactician.png`
- `architect.png`
- `protector.png`
- `slugger.png`
- `striker.png`

Recommended size: square, transparent background. The site displays them as
80px circles on the grid (`.class-card-thumb__icon`) and 120px circles on
class detail pages, both via `object-fit: cover`, so the background color
($color-surface-2) shows through the transparent margin.
