Maps

Every map from the in-game Maps menu. PVP and PVE (Horde) maps are clickable for a bigger preview - Escape hives don't have one captured yet.

{%- comment %} Every chip below (Mode/Game/Minimap Data) is a .xref-link--tip, same CSS-only hover/focus tooltip mechanism used everywhere else on the site (see .xref-tip in styles/main.scss) - each one's tooltip lists every map it currently matches, with that map's own grid thumbnail, so hovering a chip previews what clicking it will filter down to before you commit. Games_order/extras below stay hand-rolled (not a shared include) matching this file's own existing style rather than introducing a new abstraction for three call sites. {% endcomment -%}
