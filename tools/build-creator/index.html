Build Creator

Plan a Horde card loadout for any class. Pick a class below, then pick up to 5 skill cards to fill its loadout - the same 5-slot limit the game itself uses. This tool doesn't gate cards behind an account level (everything a class has is available to try), and cosmetic Heroic weapon-skin unlocks aren't real skill cards so they're left out. Perks are shown for reference only - those are fixed per class in-game, with only their rank as your choice, so there's nothing to build there. Want to browse builds other people have shared instead of building your own? See Build Viewer.
