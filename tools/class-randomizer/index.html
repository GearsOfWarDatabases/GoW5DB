Class Randomizer

Roll random classes and skill card loadouts for your squad. Every class and every card is available by default - click a card chip to exclude it, or use a class's or category's None button to drop that class out of rolls entirely. Perks are fixed per class (you only choose their rank in-game), so they're shown as reference on each result rather than rolled. The same seed + settings always give the same result.

Settings

Classes to roll
Cards per class

Cards are always unique within a single class's own roll - Horde doesn't let you equip the same card twice. Skin-unlock cards (Heroic weapon skins) are never rolled, only real skill cards.
